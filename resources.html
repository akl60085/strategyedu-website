Glossary

AI terms, explained the way we'd explain them in a workshop

LLM (Large Language Model)

The technology behind tools like Claude — trained on huge amounts of text to predict what comes next, which is why it can write, summarize, and answer questions.

Prompt

The instructions you give an AI tool. A better prompt — more context, a clear goal, an example — gets a better answer.

Hallucination

When an AI tool states something false as if it were fact. It happens to every AI tool — the skill is knowing when to double-check.

Context window

How much text an AI tool can "remember" at once in a conversation. Longer documents or chats can eventually push older parts out of memory.

Fine-tuning

Further training a model on specific data to specialize it — not something most employees ever need to do themselves.

Agent

An AI setup that can take multi-step action on its own — not just answer a question, but carry out a task using tools.

AI Tip of the Week

Short, practical, added regularly

Give it a role

"Act as a skeptical editor reviewing this for clarity" gets a sharper response than "check this for me." Framing changes the output.

Ask for the format first

Tell the AI tool exactly how you want the answer — a table, three bullet points, a short paragraph — before it starts writing, not after.

Paste the example, not just the ask

Showing one example of the tone or format you want almost always beats a paragraph describing it.
